How EMS decides and acts
  • Likely relevant comes from saved setup, host access, homepage match, imported manifest signals, and lightweight permission hints.
  • Memory Impact combines imported live process estimates and repeatable benchmark scenarios. Treat it as practical guidance, not exact renderer ownership.
  • Pause Site Extensions disables enabled extensions matched to the current site. Chrome applies this browser-wide; EMS auto-restores when the tab closes, leaves this origin, or after 30 minutes.
  • Enable / Disable changes browser-wide extension state. Some extensions can be protected by Chrome.

Enable, Disable, Pause, Lighten, Restore, and Apply change extension state across all tabs and windows. Save, Clear, Import, and Reset do not change live browser-wide extension state. Memory impact values are imported live estimates or measured scenario deltas, not exact renderer ownership.
